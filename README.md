# A Leakage-Controlled Test of Machine-Learning Stock Prediction: code and data

Code, small data files and result tables for the paper *A Leakage-Controlled Test of Machine-Learning Stock Prediction*
(R. V, A. D, S. Sikder; SCOPE, VIT Vellore). Everything is tied to the paper's sections, tables and appendices.

Licence: code is MIT (see `LICENSE`). **Price data keep their original providers' terms** (see "Data" below).

## Quick start
```bash
python -m venv venv && source venv/bin/activate
pip install -r requirements-lock.txt        # exact versions used (or requirements.txt for minimum versions)
python xai_stock_pipeline.py                # main study; writes ./results; single-threaded, roughly 10-15 minutes
```
Smoke test: `python xai_stock_pipeline.py --quick` (tiny budget; not for reporting).

| `repeat_runs.py` | Five deterministic repeats / five seeds (VII-E) |
| `planted_signal.py` | Positive control with a planted signal (Appendix B) |
| `logit_baseline.py` | Logistic-regression baseline (VII-B) |
| `walk_forward_sklearn.py` | Annual walk-forward, scikit-learn gradient boosting, wide panels (VII-F) |
| `walk_forward_annual.py` | Annual walk-forward, tuned XGBoost + TPE, wide panels (VII-F) |
| `verify_prices.py`, `repair_prices.py`, `apply_known_repairs.py` | Second-source price check and the four corrected closes (Appendix A) |
| `make_clean.py` | Builds the cleaned wide-panel files from the raw panels (offline) |
| `run_quick.sh`, `run_controls.sh`, `run_wide_xgb.sh` | Convenience wrappers for the planted-signal runs, the 100 shuffled-label controls, and the wide-panel XGBoost runs |

## Data
- `data/sp500_10stocks_daily_2013_2018.csv` (the file used in the paper) and `..._repaired.csv` (four corrected closes, Appendix A):
  daily OHLCV for 10 US stocks, from the public copy of the Kaggle "S&P 500 stock data" set
  (github.com/CNuge/kaggle-code, `stock_data/individual_stocks_5yr.zip`). Original data licence and terms apply.
- `data/planted_phi*.csv`: synthetic data generated by `planted_signal.py` (our own).
- **Wide-panel price files are not redistributed** (53/59 US stocks 2010-2025 and 43 NIFTY 50 stocks). The tickers used are in
  `dataset_info/` and in each `results_wf_*/universe.json`. To rebuild them, download daily OHLCV
  (split-adjusted, not dividend-adjusted) for those tickers from your own data provider into
  `data/stocks_2010_2025.csv`, `data/stocks_2016_2025.csv`, `data/nifty50_2010_2025.csv`
  (columns `date,ticker,open,high,low,close,volume`), run `python make_clean.py`, then e.g.
  `python walk_forward_annual.py --source csv --data data/us2010_clean.csv --test-years 2013-2025 --out results_wf_xgb_us`.
  Re-downloaded prices may differ slightly from ours, so wide-panel numbers can shift in the last decimals.

## Protocol
Features use data up to day t only; label = sign of the next-day return; chronological split; the test period (from 2017-01-01)
is never used for tuning, thresholds or model selection; walk-forward validation with a one-day purge.

## Caveats
Two original multithreaded runs of identical code gave different XGBoost results; the single-threaded pipeline reproduces
exactly. Backtest metrics for a low-signal model are fragile (paper, Section VII-E).
